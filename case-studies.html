Current focus AI / LLM AWS

AI & RAG Engineering for Enterprise Data

My present-day practice: making private enterprise data usable through LLMs. Document ingestion and chunking, embeddings and vector search, grounded generation with citations, and agent workflows that call real business systems — deployed on AWS with cost and latency budgets enforced in code.

Stack
Python, FastAPI, Amazon Bedrock, Lambda, OpenSearch, S3, DynamoDB, Step Functions, Docker
Focus
Grounded, auditable AI output instead of unverifiable model guesses
Applies to
ERP, CRM, finance and document-heavy operations
More details

Typical scope of an engagement in this area:

  • Use-case qualification — deciding what genuinely needs an LLM and what does not
  • Ingestion pipelines for PDFs, spreadsheets and database records, with incremental re-indexing
  • Retrieval design: chunking strategy, hybrid keyword + vector search, reranking
  • Grounded generation with citation tracking so every answer is traceable to a source
  • Tool-calling agents with guardrails, retries, timeouts and human-in-the-loop checkpoints
  • Evaluation harness: regression tests over prompts, measurable accuracy before and after changes
  • Token, latency and spend budgets enforced in code, with structured tracing in CloudWatch
  • Least-privilege IAM and infrastructure defined as code
